# v0.1.8

This release fixes picker closure, repeated remote initialization and shortcut preservation.

- Closing the floating picker pane restores the original focus or zoom and removes temporary candidate state. A detached Rust watcher uses Rex events, respects intentional focus changes and closed or moved source panes, and skips newer layout revisions. It retains only lifecycle metadata.
- Repeated calls with a local `source_block` override find the picker in the same source tab used for capture and placement, across pane, tab and session scopes.
- Calls made while remote installation is pending reuse the installation pane and preserve the original resume target. Concurrent invocations in the same runtime also share the pending setup.
- Default shortcut initialization queries `rex.bindings`, preserving function bindings, dynamic Lua bindings and user configuration. Comments and quoted examples no longer suppress defaults. Managed shortcuts are replaced without duplicating user bindings.
- URL punctuation cleanup runs in linear time, preserving the existing extraction rules and candidate text.

fzf remains the picker. Tab copies, Enter inserts exact text without an extra newline, and Escape or a repeated shortcut cancels. Normal operation uses Rust and Lua; Python remains limited to installation and development tooling.

Validation: Rust unit tests, CLI/installer/package/watcher tests, 264 extraction equivalence cases, formatting and Clippy, plus disposable Rex sessions covering direct closure, focus/zoom restoration, source overrides and bootstrap reuse. Release packages support ARM64 and x86_64 on macOS and Linux and include all three Rust programs, pinned fzf and SHA-256 checksums.
