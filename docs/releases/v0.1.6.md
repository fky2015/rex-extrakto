# v0.1.6

Extract Text keeps its floating picker in the source tab. When invoked from a zoomed pane, it records that pane and restores its zoom after Tab copy, Enter insert or Escape cancellation. The underlying layout remains unchanged. Zoom restoration also runs when fzf reports an error.

Restoration only changes focus while the picker still owns it. Switching to another tab or pane is respected, and a source pane that has been closed or moved is not refocused. `keep_open=true` retains the diagnostic picker and skips automatic restoration.

Extraction still follows `scope=session/tab/pane`, including hidden terminal panes and excluding the plugin's picker. First-use remote installation carries the original zoom into the resumed search. The runtime remains Rust with fzf, and Enter inserts exact text without an extra newline.
