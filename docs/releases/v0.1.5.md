# v0.1.5

Opening Extract Text from a zoomed pane now keeps that pane zoomed. Rex clears zoom when focus moves to a floating pane in the same tab, so the plugin opens a temporary search tab for zoomed sources. Copy, insert and cancel return to the original tab and remove the temporary tab. An intentional focus change while the picker is open is respected, and `keep_open=true` retains the debugging picker.

Unzoomed sources continue using the floating fzf picker. Extraction still follows the source pane's `scope=session/tab/pane`, includes hidden terminal panes and excludes the plugin's own picker. Enter inserts into the original pane without an extra newline. First-use remote installation follows the same zoom-preserving placement.
