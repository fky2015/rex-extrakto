# v0.1.3

The fzf picker now runs in Rust. Tab copies, Enter inserts exact text into the source pane without an extra newline, and Escape cancels. fzf remains the search engine. Normal plugin operations no longer require Python; installation and development tests still use it.

Cross-server invocation runs the target server's registered plugin, keeping helper paths and temporary candidate files on that server. A first invocation on a server with a missing or different version installs the matching GitHub Release package, initializes Rex config and resumes the search. Preview never triggers installation.

Release archives contain all three native programs (`rex-extract`, `rex-collect`, `rex-popup`), pinned fzf and dependency licenses. The installer accepts the new Rust picker manifest and preserves support for older Python picker packages. Config selection honors `REX_CONFIG`, then `XDG_CONFIG_HOME`, with explicit `--config` taking precedence.

The existing shortcuts, configurable `scope=session/tab/pane`, bounded capture and extraction concurrency, and exact Unicode text behavior are preserved.
