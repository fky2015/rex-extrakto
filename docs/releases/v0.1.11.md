# v0.1.11

The plugin supports Rex's native module loading through `require("plugins.rex-extrakto").setup(...)`. Repositories can live directly under the Rex configuration's `plugins/` directory, with no absolute loader paths or `package.path` changes. Setup provides default scope, capture limits and concurrency; explicit binding and action arguments take precedence. Installation preserves an existing setup call and avoids duplicate action definitions.

Normal installation uses the complete Git repository and matching prebuilt helpers from one verified release archive. The archive includes an offline Git bundle at the exact build commit. Git is optional, Cargo is unnecessary on installed servers, and dirty repositories are preserved. Runtime locations live in a state registry and actions remain pinned to immutable releases during source updates. Configuration failures restore the previous module, registry, checkout and active release.

A source checkout in auto mode identifies its version from `plugin.json` and installs the matching release on first use. Explicit dev mode reports the build command when native helpers are missing. fzf, Tab copy, exact Enter insertion, repeated-shortcut cancellation, scope selection and focus/zoom restoration retain their existing behavior.

Installation and isolated Git fixtures disable automatic maintenance, preventing detached housekeeping from racing with checkout rollback or temporary directory cleanup.
