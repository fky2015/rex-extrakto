# v0.1.4

First-use installation now checks and reloads the Rex server that opened the installation terminal, including servers using a custom socket. The installation environment explicitly selects the target listener before invoking the installer, so a successful download resumes the original search on that server.

This retains v0.1.3's Rust picker, fzf search engine, exact copy and insertion behavior, and automatic remote setup. Python is used only for installation and development tests.
