rex-extrakto brings terminal text extraction and fzf search to Rex.

- Search words, paths, URLs or complete lines with `scope=pane/tab/session`.
- Tab copies; Enter inserts into the invoking pane without an extra newline.
- Tokio runs bounded asynchronous captures, while CPU extraction reuses a shared Rust module.
- Defaults: `jobs=4`, `extract_jobs=1`, 3,000 recent lines per pane and 2,000 merged candidates.
- macOS and Linux releases support x86_64 and ARM64. Linux helpers are built with musl.
- Each package includes prebuilt helpers, fzf and dependency licenses. The installer verifies SHA-256, initializes Rex config and preserves custom bindings.

Install on the machine running the Rex server:

```sh
curl -fsSL https://raw.githubusercontent.com/fky2015/rex-extrakto/main/scripts/install.sh | sh
```

Rex CLI and Python 3.8 or newer are required. No Rust toolchain or administrator access is needed.

For machines without GitHub access, download the matching archive and `SHA256SUMS` elsewhere, transfer them with `scripts/install.py`, then run:

```sh
python3 install.py --archive ARCHIVE.tar.gz --checksum-file SHA256SUMS
```
