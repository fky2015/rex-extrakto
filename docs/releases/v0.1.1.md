Fix first installation when GitHub's anonymous API quota is exhausted.

The installer now resolves the latest version through the public Release page and downloads archives and `SHA256SUMS` directly. Fixed-version installs use the corresponding Release download links. Installing a public release no longer requires a GitHub API request or token.

The four platform packages still include both Rust helpers, fzf v0.75.0 and dependency licenses. Existing bindings, scope and concurrency settings are preserved.

Install or upgrade on the machine running the Rex server:

```sh
curl -fsSL https://raw.githubusercontent.com/fky2015/rex-extrakto/main/scripts/install.sh | sh
```
